## Implementation interpretation

- Use **Siriranee Thai Massage** consistently as the public website name.
- Keep the website English-only and omit a language selector.
- Use deep aubergine heroes, warm-gold actions, ivory surfaces, editorial serif
  headings, subtle lotus linework, rounded cards, and restrained shadows.
- Adapt organically curved image boundaries with CSS rather than slicing UI from screenshots.
- On mobile, stack hero content, use horizontally scrollable filter chips, collapse
  cards to one column, and make booking actions easy to reach.
- Treat names, ratings, dates, statistics, claims and staff portraits visible in
  the mockups as placeholders unless independently confirmed.
